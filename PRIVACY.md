# Privacy Policy — Full Names for Productive

_Last updated: 2026-10-15_

Full Names for Productive does not collect, store, transmit or sell any data.

- The extension runs only on `https://app.productive.io/*`.
- It reads the text of elements on the page that are visually cut off (shown with "…") and displays that same text in a tooltip next to your mouse pointer.
- This happens entirely inside your browser. The extension makes no network requests, uses no analytics, and saves nothing (no cookies, no local storage, no sync storage).
- It requests no extension permissions beyond running on the Productive web app.

This extension is an independent project and is not affiliated with or endorsed by Productive.

Questions: open an issue in the project's repository.
