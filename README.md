# Full Names for Productive

Chrome extension that shows the full text of cut-off names ("…") in [Productive.io](https://productive.io) in a tooltip after a short hover. It's useful for long client, project and budget names that look identical when truncated.

## How it works

- One content script (`extension/content.js`), plain JavaScript, no build step, no dependencies.
- Listens for `mouseover` on the document. Dynamically rendered dropdowns and menus work without extra code.
- An element counts as truncated when it has `text-overflow: ellipsis` or `-webkit-line-clamp` and its content overflows. That is how Productive truncates names: the full text stays in the DOM.
- After 400 ms it shows a tooltip. The tooltip lives in a closed shadow root and uses the Popover API (top layer), so it appears above Productive's menus. It has `pointer-events: none`, so hover menus don't close.
- Hides on mouse-out, click, scroll, wheel, any key, window blur or tab switch.
- If the element has a native `title`, the extension removes it while its own tooltip is shown and restores it afterwards, so two tooltips don't stack.

## Develop / try locally

1. Open `chrome://extensions`, enable **Developer mode**.
2. **Load unpacked** → select the `extension/` folder.
3. Open Productive and hover a cut-off name. After editing `content.js`, click the reload icon on the extension card and refresh Productive.

There's also a test page with example cases: serve the repo root (`python -m http.server 8765`) and open <http://localhost:8765/test/fixture.html>. It loads `content.js` directly.

## Release

1. Bump `version` in `extension/manifest.json`.
2. `powershell -ExecutionPolicy Bypass -File scripts/package.ps1` → creates `dist/full-names-for-productive-<version>.zip`.
3. Upload it in the [Chrome Web Store developer dashboard](https://chrome.google.com/webstore/devconsole). Listing copy and checklist: [STORE_LISTING.md](STORE_LISTING.md).

Icons are generated by `python scripts/make-icons.py` (needs Pillow; dev only).
